Immutable Gaming OS. Zero Compromises.

Built for Gamers. Secured by Design.

Every layer engineered for performance, security, and reliability.

🔒

Immutable Architecture

Read-only root filesystem powered by Btrfs snapshots. Every update is atomic — roll back instantly if anything breaks. Your system state is always recoverable.

🛡️

Advanced Security

SELinux mandatory access control combined with Bubblewrap sandboxing. Apps run in isolated namespaces with minimal privileges. Attack surface reduced to near zero.

🎮

Unified Input Engine

Native gamepad support across the entire desktop environment. No extra drivers, no Steam overlay hacks. Every application sees your controller natively.

📱

Android Integration

Run Android apps via Waydroid with full GPU acceleration. Built-in APK installer, seamless clipboard sharing, and shared file system between Linux and Android layers.

⚡

Performance Engine

ZRAM compression for expanded effective memory. cgroups v2 throttler isolates background processes from gaming workloads. Every CPU cycle goes where you need it.

🔄

Auto OTA Updates

Incremental delta patches delivered automatically. Full rollback support if an update causes issues. Your games, saves, and configs stay untouched across every update.
